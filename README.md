# 출근런: 오늘도 간신히 사회인

출근길을 달리며 멘탈을 지키고, 회사에 도착했을 때의 상태에 따라 10가지 미래 중 하나를 보는 2D 러너 게임입니다.

## 소개

"커피 한잔 값의 게임으로 유저들의 마음을 사로잡자!"를 주제로 한 게임 제작 공모전 출품작입니다.

매일 똑같은 출근길도 그날의 선택에 따라 결말이 달라집니다. 플레이어는 2~3분의 출근 한 번으로 서로 다른 10가지 미래를 하나씩 만나게 됩니다. 커피 한 잔의 값으로 다양한 미래를 맛보는 경험을 만드는 것이 기획 의도입니다.

## 게임 방법

캐릭터는 자동으로 달립니다. 멘탈이 0이 되기 전에 회사에 도착하세요.

| 키 | 동작 | 설명 |
| --- | --- | --- |
| `C` | 점프 | 땅에 있을 때만 가능 |
| `Z` | 슬라이드 | 누르고 있는 동안 유지 |
| `X` | 패링 | 경고 동작이 나온 뒤 0.4초 안에 입력. 한 번 누르면 2초간 다시 누를 수 없음 |
| `Space` | 엔딩 대사 넘기기 | |
| 마우스 | 메뉴, 이벤트 선택지, 팝업 확인 | |

## 게임 요소

### 멘탈

- 100에서 시작해 초당 1씩 줄어듭니다.
- 장애물에 닿으면 5씩 줄어듭니다.
- 도착까지 약 150초가 걸리므로 커피 없이는 도착할 수 없습니다.

### 장애물

3초마다 하나씩 가중치 확률로 등장합니다.

| 장애물 | 특징 |
| --- | --- |
| 바리케이드, 쓰레기, 구멍 | 닿으면 멘탈 -5 |
| 날벌레 떼, 전단지 | 멘탈 -5, 3초간 화면을 가림 |
| 물웅덩이 | 멘탈 -5, 비가 올 때만 등장 |
| 도를 아십니까 외 1종 | 피할 수 없음. 패링에 실패하면 3초간 붙잡힘 |

### 커피

| 커피 | 얻는 곳 | 효과 |
| --- | --- | --- |
| 자판기 커피 | 자판기 (45초마다 등장) | 멘탈 +20 |
| 편의점 캔커피 | 카페 | 멘탈 +5, 다음 장애물 1회 무시 |
| 프리미엄 드립 커피 | 카페 | 멘탈 +15, 10초간 장애물 생성 정지 |
| 에스프레소 | 카페 | 멘탈 +10, 10초간 2배속 (받는 피해 2배) |

카페는 낮은 확률로 등장하거나 이벤트 보상으로 나오며, 능력 커피 3종 중 하나를 무작위로 줍니다.

### 선택 이벤트

달리는 도중 게임이 멈추고 두 선택지 중 하나를 고르는 이벤트가 6종 있습니다.

| 이벤트 | 선택 1 | 선택 2 |
| --- | --- | --- |
| 가방 속 오래된 커피 | 마신다: 3초간 3배속과 무적, 또는 20초간 화면 상하 반전 | 안 마신다 |
| 공사 중인 지름길 | 들어간다: 목표 거리 -5%, 45초간 장애물 증가 | 돌아간다 |
| 주인 없는 지갑 | 돌려준다: 카페 등장, 목표 거리 +5% | 가진다 |
| 갑자기 내리는 비 | 가방을 쓴다: 10초간 멘탈 감소 1.5배 | 뛰어간다: 30초간 물웅덩이 피해 2배 |
| 학교 앞 등교 인파 | 뚫고 지나간다: 목표 거리 -10% | 피해간다: 자판기 등장 |
| 커피 샘플링 | 받는다: 멘탈 +20, 50% 확률로 붙잡힘 | 거절한다 |

엔딩은 10종입니다. 도착했을 때의 멘탈로 기본 엔딩 5종이 갈리고, 특정 행동을 하면 히든 엔딩이 열립니다. 한 번 본 엔딩은 도감에 저장되어 다시 볼 수 있습니다.

## 실행 방법

1. 저장소를 내려받습니다.

   ```bash
   git clone https://github.com/FOUR-TEEMOS/ChyulgeunRun.git
   cd ChyulgeunRun
   git checkout v1.0
   ```

2. Unity Hub에서 Unity **6000.1.3f1**로 프로젝트 폴더를 엽니다.
3. `Assets/Scene/IntroScene/StartScene 1.unity`를 열고 Play를 누릅니다.

기준 해상도는 1920×1080입니다.

빌드할 때는 `File > Build Profiles`의 씬 목록에서 `StartScene 1`을 맨 위로 옮겨야 합니다. v1.0에서는 `EventScene1`이 첫 번째로 등록되어 있습니다.

## 기술 스택

- Unity 6 (6000.1.3f1), Universal Render Pipeline 2D
- C#
- TextMesh Pro
- DOTween (화면 전환 페이드, 인트로 연출)

## 프로젝트 구조

```
Assets/
├── Scene/
│   ├── IntroScene/      타이틀(StartScene 1), 인트로 컷(StartScene 2)
│   ├── GameScene        달리기 본편
│   ├── EventScene/      선택 이벤트 화면 6개
│   └── EndingScene/     엔딩 화면, 엔딩 도감
├── Scripts/
│   ├── Player/          플레이어 조작, 패링, 게임 매니저(멘탈, 거리, 속도)
│   ├── Obstacles/       장애물 생성과 이동, 충돌, 시야 방해
│   ├── Coffee/          커피 능력, 자판기, 카페, 커피 팝업
│   ├── Events/          이벤트 발생, 선택 결과 적용
│   ├── Ending/          엔딩 판정, 연출, 해금 저장, 도감
│   ├── Background/      배경 스크롤과 전환
│   ├── Intro/           화면 전환 페이드, 인트로 연출
│   ├── Scene/           메뉴 버튼의 씬 이동
│   └── UI/              HUD, 선택 팝업
├── Prefabs/             장애물, 커피, 배경, 이벤트 프리팹
└── Art/                 그림 에셋
```

## Known Issues (v1.0)

v1.0은 제출 당시 상태 그대로이며 다음 문제가 있습니다.

- 엔딩 5번과 9번이 조건을 만족해도 나오지 않습니다.
- 패링에 실패해도 멘탈 피해가 들어가지 않고 붙잡히기만 합니다.
- 남은 거리가 700 미만일 때 이벤트 후보가 의도와 다르게 골라집니다.
- 자판기가 등장하기만 해도 커피를 마신 횟수가 올라갑니다.
- 팝업이 떠 있는 동안에도 조작 입력이 막히지 않습니다.
- 게임을 끄지 않고 다시 플레이하면 첫 판과 이벤트가 다르게 나옵니다.
- 난이도 조정이 필요합니다.
- 화면 전환(인트로 연출, 메뉴 사이 페이드)이 길고 건너뛸 수 없습니다.
- 일부 애니메이션이 매끄럽지 않습니다.
- 효과음과 배경음이 없습니다.
